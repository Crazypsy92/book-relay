# logs｜迁移与整理记录

## migration-manifest.csv

`migration-manifest.csv` 是仓库初始迁移时生成的清单，记录当时的复制、重复上传、用户补交文件、未迁移的近完整原文副本及新建说明文件。

它是**初始迁移审计记录，不是当前仓库的实时文件清单**。此后新增的第01—35篇和第102—124篇等内容，以 Git 提交历史、四卷索引和 `work/maoxuan_project_progress.md` 为准。

## 维护规则

- 不要把后续新增文件直接伪装成初始迁移内容。
- 若未来需要完整库存清单，应另建带日期的仓库快照清单，保留原始迁移记录。
- 文件哈希、重复文件和未上传材料的边界以原始清单中的说明为准；不将 Git Blob SHA1 冒充 SHA-256。
