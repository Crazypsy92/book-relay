# 《寻乌调查》阅读导览

## 作品与版本锚点

- **作者：**毛泽东。
- **调查时间：**1930年5月；共产党员网所载转录的前言末署1931年2月2日。该日期属于可访问转录所呈现的题署，仍须在目标纸本核对。
- **优先底本：**《毛泽东文集》第一卷，中共中央文献研究室编，人民出版社，1993年12月。中共中央党史和文献研究院书刊介绍确认编辑、出版社和出版时间；广州图书馆目录确认第一卷题名、编者、1993年出版记录及载体信息。
- **页码边界：**一篇中共中央党史和文献研究院研究文章引用该版第118—245页，可作为书目页码线索；本项目目前未取得并逐页检查1993纸本，故该范围记为“二手引文所报、待纸本复核”。正文引文暂按章、节定位，不把网络转录页码当作纸本页码。

## 原文可访问范围与结构

共产党员网目前可公开阅读的《寻乌调查》页面呈现前言及五章全文。页面没有注明所据印次、原书页码或可复核的版本说明；公开阅读不等同于获得复制或再发布许可。本项目只用它核对结构并供后续逐单元阅读，笔记保留原创梳理、分析和定位，不搬运整本或大段原文。

五章依次为：寻乌的政治区划、寻乌的交通、寻乌的商业、寻乌的旧有土地关系、寻乌的土地斗争。该转录在第二至第五章列有39个编号主节；第三章“寻乌城”下还有行业条目，第四章“剥削状况”下还有分项。各版的节名、层级、注释和篇末刊印说明仍需对照1993版逐项核定。

> [!warning] 证据边界
> 调查报告中的记述需要继续区分调查者整理、受访者陈述、观察、统计口径、分析判断、政策主张和后出研究。公开转录中的数字和个案不自动等于独立复核过的事实；寻乌一地也不能直接代表全国。纸本页码仅在实际核对指定版后填写。

## 文体路由与阅读方法

本书归入**调查研究与报告**，文本结构以纪实材料、分类描述和基于调查材料的分析为主；其中的政策判断和历史解释另作论证核读。复用 `unified-content-notes` 的知识纪实、调查报告路由、来源边界和质量检查模块；调查方法本身成为论点时再调用方法笔记。对人的处境与伦理代价，只依据有来源的生活材料分析，不套用小说或一般叙事模板。

每个单元围绕实际证据记录：调查问题与待检假设、地点和时间、参与者与资料来源、信息获取方式及其偏差；区分被访者说法、调查记录、数字、推断和政策建议；追踪从材料到判断的推理链。涉及生计、债务、土地、税费、商业、妇女劳动或社会冲突时，只写原文或可靠外部材料支持的内容，并保留缺席群体、样本偏差和未知项。不得由局部调查推出全国规律。

## 阅读路线（九个单元）

按报告内部的主题与材料密度分段，不按五章均分。前言作为全书方法和材料边界，每单元按需回看；计划分段以网页转录可见结构为基础，待1993版目录和页码复核后微调。各单元完成状态只见 [`work/classics_reading_progress.md`](../../../work/classics_reading_progress.md)。

| 单元 | 原文范围 | 本段在报告中的作用与核查重点 |
| --- | --- | --- |
| 1 | 第一章、第二章 | 先建立县域行政区划与水陆交通背景；核地名、里程、通讯与节点关系，不把空间描述误读成经济因果 |
| 2 | 第三章（一）至（七） | 梳理县外商路、进出口与重要圩市；检查货物流向、计量 / 价格口径、信息来源和季节或路线条件 |
| 3 | 第三章（八）（1）至（12） | 阅读县城及主要行业前半部分；区分经营者、商品、店员和交易关系，留意商业数据是怎样取得的 |
| 4 | 第三章（八）（13）至（25） | 阅读手工业、服务、圩场及人口政治位置等条目；检视分类如何连接生计、社会身份与政治判断 |
| 5 | 第四章（一）至（六） | 阅读农村人口成分、旧有田地分配及地主、富农、贫农分类；核定义、统计分母和分类重叠，追问未单列群体 |
| 6 | 第四章（七）及（八）A | 阅读山林制度与地租 / 劳役 / 土地交易；分析权利安排和负担如何落到家庭，避免把概括统计套到每户 |
| 7 | 第四章（八）B、C及（九） | 阅读借贷、税捐和文化教育；分开债务关系、征收口径与调查者评价，核实材料覆盖和未记录的生活成本 |
| 8 | 第五章（一）至（八） | 阅读分地方法、山林池塘房屋、区域标准及公共土地；比较人口、劳动力、地力、家庭成员等分配依据 |
| 9 | 第五章（九）至（十七） | 阅读分配节奏、阻力、原耕、非农民、债务、土地税及妇女参与；追踪执行主体、利益冲突、政策变化和证据边界 |

单元9完成后，才开展全书综合：调查设计与资料形成、分类和证据链、社会结构及普通人处境、政策推理的因果范围、记录中的缺席者、调查方法可迁移的条件。之后单独进行质量验收，不在每轮重复整书总结。
