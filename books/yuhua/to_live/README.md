## 增量深化标准（用户2026-11-25确认）

**这是对已有小说精读成果的二次拓展，不是重复改写剧情。** 用户提供的《活着(1).md》原稿已具备完整剧情、人物与关系、六个思想问题、四个文学手法、作者访谈及评论、七个情节回看。其他候选书也已具备类似板块。定时任务应当先查“已有内容覆盖清单”，只补原稿缺失的具体证据、观点差异或细读层次，不再按老模板重新产出十二个同名栏目。

每个新单元至少要具备下列可验收增量：
1. **一个有事实来源的细读锚点**：取既有笔记或可核实材料中确有的场景、叙事结构或文本细节，说明叙述选择如何改变理解；不从梗概编出原著原句。
2. **一种文学观察**：从时间、叙述视角、铺排、省略、反讽、重复、意象或体裁选择中择一做真正的「细节 → 手法 → 阅读作用」分析，不能只是定义术语。
3. **一组人文张力**：同情与追责、自由与处境、亲情与伤害、道德判断与命运结果等，需要给出两面证据并保持可反驳性，不能再写一遍“活着很重要”。
4. **一种有出处的不同读法或跨书对照**：优先作者创作谈与经署名的评论；必要时对照已上传《文城》《许三观卖血记》《兄弟》《我与地坛》等既有笔记，不能将整理者推测写成原著事实。
5. **一个能够推动重读的问题**：明确回到哪一场景，如何验证判断，避免套用“我们要学会珍惜”一类感想。

**增量检查方式：**先写“已覆盖/待补”的对照，再进行补充；不重复已有剧情梗概、作者简介、主题口号或总结。若没有新的可靠材料，就明确写出缺口并停在资料层，不伪造“新增研究”。只有查证和分析质量过关才标记单元完成；不能只凭字数或 Markdown 通过验收。先完成当前书的 U02—U05 和 FINAL，**不能**每小时自动改下一本。

## 处理原则

1. **每轮只完成下一个单元**，正文直接更新 `reading_notes.md` 的对应位置，不能每轮另建一篇同内容文件。
2. 场景先行，写清人物处境、实际动作、对话的证据范围与关系后果；不拆成机械的主题报告，不反复写“我读到/我认为”，也不堆煽情的形容词。
3. 对既有用户资料应作复用和事实复核，不能把旧导读直接当原著文字或逐章证明；外部评论、作者访谈与自写理解分别标记。
4. 绝不将1992《收获》初刊、1993扩充本、后出通行本或1994电影情节混写，无法核实的细节标记待核，不编对话、页码、章节号、内心独白。
5. 短引文需有可回查出处；未取得用户提供的合法文本时，不转载受版权保护的原文全文或连续长段。
6. 每轮更新 [[work/classics_reading_progress|唯一进度台账]]，普通提交 `main`，检查 Obsidian 双链与 Callout，回报完成/未完成以及证据缺口。原有鲁迅三书、毛选、寻乌调查及雾月十八日的结项材料一律不改。
7. 五单元完成后**另做 FINAL 轮**。完成并终验后暂停同一接力定时任务，不擅自进入《兄弟》或其他书。
