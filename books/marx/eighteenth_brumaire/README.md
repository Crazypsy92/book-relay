# 《路易·波拿巴的雾月十八日》阅读导览

## 作品与版本

- 作者：卡尔·马克思。写作时间依作品数字目录约为1851年12月至1852年3月；马克思1869年第二版序言说明写作在1851年末开始，原计划周刊未成，后在纽约《革命》不定期刊物首期刊出。原著为德文。
- 本地可识别的中文单行本：人民出版社2018年3月版，编译者为中共中央马克思恩格斯列宁斯大林著作编译局，ISBN 978-7-01-018983-3。图书记录列165页，目录包括编者引言、马克思1869年第二版序言、恩格斯1885年第三版序言、正文七章、注释、人名索引和插图。元数据据[南开大学馆藏记录](https://space.nankai.edu.cn/mspace/searchDetailLocal/me1221c0458109f3ff190f61dd2a49991)及[新华书店图书记录](https://item.xhsd.com/items/1010000104190930)交叉核对；没有声称亲见这一本纸本。
- 本轮试读文本：中文马克思主义文库所载《马克思恩格斯全集》第八卷数字转录。该网页标明原著德文，并提供章节标题、版本说明和注释；《全集》第八卷译后记说明所用中译在既有俄译基础上参照德文原著校订。它不是上述2018年单行本的逐字核对件，也不是作者手稿或纸本影印。
- **页码边界：**本项目按章和段落定位，不填2018年版或其他译本的页码。前言、编者引言、注释及排版都会改变页码；未取得用户手头版本，不能建立一一对应页码或声称译文一致。网络转录中的章号、段首和链接可用于回查，但不同版本的措辞、注释和标点仍需以具体版本复核。

## 原著结构

可访问中文目录实际列出两篇序言与七章：一《1848年2月至1851年12月》、二《共和党的倒台》、三《路易·波拿巴的崛起》、四《小资产阶级民主派的失败》、五《制宪国民议会和波拿巴》、六《波拿巴的胜利》、七《总结》。这是跨越1848年二月革命、第二共和国政治冲突直至1851年12月政变的政治历史分析，并以对既往革命语言的反思开篇；不是按人物逐个介绍的传记。
