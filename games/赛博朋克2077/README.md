## 资料使用规则

1. **先读六份整理后的主文档。** 原始材料只在需要核对讲者原话、ASR 识别或处理过程时打开。
2. 游戏剧情事实、视频讲者的解释、外部资料和个人分析必须区分；视频转录不能直接替代游戏原作证据。
3. 任务分支、角色生死和结局选择需要注明触发条件，不能把某一种玩家路线写成唯一剧情。
4. 游戏本体、《往日之影》和《边缘行者》分开讨论；世界观有关联，不代表人物经历和时间线可以混写。
5. 原始转录不覆盖、不静默修正；校订稿若没有人工核听，必须明确标注。
6. 新增资料优先融合进对应主文档，避免重新建立大量零散英文文件。
