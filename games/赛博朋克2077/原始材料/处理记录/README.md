# 转录处理记录

这里保存 B 站转录从原始 ASR 到校订阅读版、候选检查和 Obsidian 整理的过程记录。它们用于追溯处理过程，不是推荐的日常阅读入口。

## 文件说明

| 文件 | 用途 | 使用时注意 |
|---|---|---|
| 转录处理状态.json | 9 条视频的来源、BV 号、处理状态、模型与转录文件映射 | 9 条均记录为 COMPLETED；仅表示转录文件已归档 |
| 03_候选问题清单.json | 第 03 期中检测到的重复片段候选 | 候选均需人工复核，不能自动当作错误 |
| 03_校订稿_未人工核音.md | 第 03 期校订阅读稿 | 未进行人工核听，不能称为逐字核对稿 |
| 03_校订差异记录.json | 校订过程中保留的候选标记和差异信息 | 用于追溯处理动作 |
| 03_Obsidian整理版.md | 第 03 期观点摘要与 Obsidian 阅读版 | 其中引用的原始转录已改为链接到本专区归档 |

## 重要边界

- 原始转录在上一级“视频转录”目录，作为原始材料保留。
- 处理记录不替代游戏原作，也不代表视频讲者的所有说法都已独立核验。
- 第 03 期原始 ASR 文件与“视频转录”目录中的第 08 篇内容相同，因此只保留一份，避免重复占用空间。
