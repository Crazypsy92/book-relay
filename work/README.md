# work｜正式精读笔记与项目进度

本目录保存编号精读笔记、唯一进度文件、质量检查脚本和必要的历史导入副本。

## 主要入口

- [唯一进度文件](maoxuan_project_progress.md)：当前篇目、返修状态、证据记录和下一项任务。
- [四卷导航](../books/maoxuan/README.md)：按人民出版社1991年第二版实际卷次查找笔记。
- [Obsidian Callout 检查脚本](check_obsidian_callouts.py)：检查 Obsidian Callout 格式。

## 文件规则

- 正式篇目文件统一使用三位数字前缀：`001_...`、`016_...`、`125_...`。
- 第99篇的两个版本均以 `099_` 开头；正式稿和补充参考稿的用途以第四卷索引和进度文件为准。
- `imported_notes/` 仅保存历史导入副本，不计入正式篇目，不参与主编号排序。
- 模板和样例目录已按用户要求清理，不再建立独立模板副本。
- 未经用户明确要求，不删除已有书籍资料、正式笔记或历史记录。
