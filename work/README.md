# work｜项目进度、跨文体阅读与工具

本目录只保存项目进度、跨文体阅读方法和必要的质量检查脚本。正式精读笔记统一归档在对应 `books/` 目录；游戏专题资料独立归档在 `games/`。**《毛泽东选集》157篇正式精读笔记已按四卷归档到 `books/maoxuan/volume_01/` 至 `volume_04/`，不再放在本目录。**

- [毛选唯一进度文件](maoxuan_project_progress.md)：四卷篇目完成状态、返修记录、来源边界和归档说明。
- [毛选四卷总索引](../books/maoxuan/README.md)：进入对应卷目录查找正式篇目。

## 维护规则

- 毛选正式篇目按人民出版社1991年第二版实际卷次存放在对应 `books/maoxuan/volume_XX/` 目录，文件名使用三位数字前缀。
- 第99篇正式稿保存在第四卷主目录；补充参考稿单独存放于 `../books/maoxuan/volume_04/references/`，不计入正式篇目。
- 跨文体经典作品的一部作品优先保留一份完整精读主笔记，归档在对应 `books/` 目录；`work/` 只保留进度与方法记录。只有独立专题确有长期价值时才另建文件。
- 未经用户明确要求，不删除已有书籍资料、正式笔记或历史记录。
