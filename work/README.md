# work｜项目进度、跨文体阅读与工具

本目录只保存项目管理文件、跨文体经典精读资料、质量检查脚本和必要的历史导入副本。**《毛泽东选集》157篇正式精读笔记已按四卷归档到 `books/maoxuan/volume_01/` 至 `volume_04/`，不再放在本目录。**

## 主要入口

- [毛选唯一进度文件](maoxuan_project_progress.md)：四卷篇目完成状态、返修记录、来源边界和归档说明。
- [毛选四卷总索引](../books/maoxuan/README.md)：进入对应卷目录查找正式篇目。
- [跨文体经典精读进度](classics_reading_progress.md)：经典作品的唯一单元状态、来源边界与下一项任务。
- [跨文体精读主笔记](eighteenth_brumaire_reading_notes.md)：《路易·波拿巴的雾月十八日》五个阅读单元及全书综合分析；作品导览见 [对应目录](../books/marx/eighteenth_brumaire/README.md)。
- [跨文体方法调整记录](cross_genre_reading_method.md)：文体路由、共享流程和试运行边界。
- [Obsidian Callout 检查脚本](check_obsidian_callouts.py)：检查 Obsidian Callout 格式。
- [历史导入副本](imported_notes/README.md)：只用于追溯初始迁移，不计入正式篇目。

## 维护规则

- 毛选正式篇目按人民出版社1991年第二版实际卷次存放在对应 `books/maoxuan/volume_XX/` 目录，文件名使用三位数字前缀。
- 第99篇两个版本均保留在第四卷目录；正式稿与补充参考稿的用途以第四卷索引为准。
- `imported_notes/` 仅保存历史导入副本，不计入正式篇目，不参与主编号排序。
- 跨文体经典作品的一部作品优先保留一份完整精读主笔记；只有独立专题确有长期价值时才另建文件。
- 未经用户明确要求，不删除已有书籍资料、正式笔记或历史记录。
