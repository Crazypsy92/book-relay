这里保留《毛泽东选集》精读笔记的原始路径。为兼容 Obsidian 相对链接和历史引用，**不要为了目录整齐而批量移动或重命名现有笔记**。

## 主要入口

- [唯一进度文件](maoxuan_project_progress.md)：当前篇目、返修状态和下一项任务。
- [主精读模板](14_template_practice_on_the_relation_between_knowledge_and_action.md)：沿用的主要结构参考。
- [四卷导航](../books/maoxuan/README.md)：按卷查找第01—124篇正式编号笔记。
- [Obsidian Callout 检查脚本](check_obsidian_callouts.py)：检查项目笔记中的 Callout 结构。

| 路径 | 用途 |

## 文件维护规则

- 正式篇目只在对应编号文件中维护。
- `templates/` 与 `imported_notes/` 中的副本用于追溯，不要与正式文件并行编辑。
- 第14篇存在同内容的正式笔记与主模板入口；第99篇正式稿为 `99_smash_chiang_kai_s_offensive_in_self_defense.md`，补充参考稿为 `99_smash_chiang_kai_shek_s_offensive_in_self_defense.md`。两份文件均保留，后续常规编辑只修改正式稿。
- 新增篇目先核对四卷索引和进度文件，再按既有命名方式建立文件。
