# 跨文体精读方法调整记录

## 调整背景

《毛泽东选集》按篇目逐篇推进的办法适用于该项目，但不应被直接扩展为所有思想作品的“每章一份摘要”。历史分析、调查报告、理论著作、演讲与文学作品的组织方式不同；统一的是资料真实性、定位、证据层级、独立评价和知识关联，变化的是分析焦点与阅读单元。

## 可复用的阅读流程

1. **定义动作**：总结、解释或只改格式；format-only 仍不得擅改语义。
2. **确认结构**：论证、叙事、纪实、方法、对话或混合；一部书可以组合结构。
3. **选择文体视角**：历史政治、调查报告、理论哲学、演讲随笔、小说文学；视角叠加在结构上，不替代结构。
4. **核对文本与版本**：读取作品目录、序言、版本说明，记录译者、版次和材料完整度；页码只在能确定当前版本时使用。
5. **建立证据层级**：分别标注作品主张、同时代材料、后出研究、编辑说明、独立核实事实、整理者解释和未知。
6. **划分接力单元**：优先按实际论证 / 事件机制和篇幅决定，可跨章节或在长章内分段；每轮完成一个单元，并写明下一个单元。
7. **形成精读**：梳理文本提出的问题、论证 / 叙事过程、例证、反例、重要关系和限制；不以换句话说代替分析。
8. **复核与关联**：核对引用定位、来源可访问范围、表格与链接目标；更新该作品的唯一进度文件，不改写其他已完成项目。

## 表达视角补充：让笔记像真实的阅读过程，而不是模拟“我”

《寻乌调查》完成后，用户明确要求精读从自己的阅读、理解、质疑和反思出发，不写成“报告指出 / 本文认为”的会议纪要。后续反馈又指出：即使频繁使用“我读到 / 我不愿 / 我想”，也不等于有了个人阅读感；如果每段都由相似的第一人称句式起头，反而像模型在代替读者表演感受。

**统一原则：保留读者视角，不机械堆叠第一人称。** 第一人称只在确实表达初始反应、判断变化、个人保留或未解问题时自然出现；其余段落可以直接从人物、场景、行动和结果写起。不要把“我”全部改成“读者”，也不要把每段改成“我认为”。不能虚构用户未表达过的亲身经历、强烈情绪或阅读时刻。

小说精读优先参考用户认可的《文城》笔记节奏：先让人物在具体生活场景中出现，按处境、行动、关键对话、后果和关系变化连续叙述；解读嵌在情节推进中，而不是每段末尾补一句主题结论。阅读带入感来自人物命运的连续、场景细节和前后认识的变化，不靠形容词、感叹号或“让我停下来”之类口头禅。少量阅读停顿只放在真正值得回看的节点，不把正文切成密集的分析卡片。

避免每一段都走同一套“情节—我感受—抽象概念—问题”流程。段落之间要有自然承接：前一场景造成的后果，引出人物下一步选择；新信息出现时，回头修正此前的判断。让观点从故事里长出来，不先把“精神胜利法 / 看客 / 革命 / 人性”等概念贴到人物身上。

来源、版本、材料缺口和文本定位集中放在导览或必要的文末说明中，不在每个叙事段落后重复免责声明。事实、人物自述、叙述者语气、外部评论与读者解释仍须分清；不为追求带入感补造原作没有的心理、对白、动作、环境或结局。

这条规则适用于小说及其他叙事作品。历史、理论、调查报告等非叙事文体仍按其材料结构组织，但同样避免把“我”或“作者认为”变成每段的固定开头。

**已验证的对照样本（2026-11-23）：**《阿Q正传》九章五阶段深读得到用户认可，后续将其用作“完整情节先行、人物复杂性保留、阅读判断自然出现”的范例，而不是固定篇幅模板。用户要求其余32篇按此优化：24篇补故事过程，8篇《故事新编》保留详细场景并增阅读回望；阿Q原文保持不动。通用规则与正反例已经迁入 [unified-content-notes](https://github.com/Crazypsy92/unified-content-notes) 的 `modules/novel-analysis.md` 和 `core/quality-check.md`，后续优先复用 Skill，无需每次临时重述。

## 已有合订本的单篇深化规则

当用户提供或仓库中已经存在多篇作品的合订本，而其中某篇已有简要精读时，不应默认另建该篇的独立主笔记。先检查合订本中已有的情节理解、人物分析和跨篇主题，再把新的细读单元、场景回看和全篇反思融合到该篇原有位置；合订本的跨篇联读继续保留，不重复写第二套专题总论。版本、来源和阅读路线可以保留在单篇导览中；历史独立正文如需保留，改成指向合订本唯一正文的兼容入口。

**整本风格返修的覆盖要求：** 当用户指出一份合订本仍有统一的叙述问题，试水篇只用于校准方向，不等于整项任务完成。按目录逐篇审计和返修所有约定篇目，同时检查卷首导读、卷末回望、跨篇专题与场景回看；完成后核对篇目数量、标题锚点、Obsidian 链接和 Callout，不以单篇示例代替全量验收。
