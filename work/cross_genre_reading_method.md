# 跨文体精读方法调整记录

## 调整背景

《毛泽东选集》按篇目逐篇推进的办法适用于该项目，但不应被直接扩展为所有思想作品的“每章一份摘要”。历史分析、调查报告、理论著作、演讲与文学作品的组织方式不同；统一的是资料真实性、定位、证据层级、独立评价和知识关联，变化的是分析焦点与阅读单元。

## 复用既有 unified-content-notes Skill

已检查 `Crazypsy92/unified-content-notes` 的 `SKILL.md`、动作与结构路由、来源边界、质量检查，以及已有的论证、纪实、叙事、小说、人文和关系模块。原有模块已覆盖多个结构 / 专题，但没有明确区分五类跨文体视角，也没有历史政治分析专项。此次沿用“一个 Skill、模块按需继承”的架构：

- 新增 `modules/genre-reading-router.md`，明确五类视角并路由到已有模块。
- 新增 `modules/historical-political-analysis.md`，补充时间线、行动者 / 制度、利益和联盟、因果链、政治表述、作者位置和有来源的人文处境。
- 更新 `core/structure-router.md` 和 `SKILL.md`，区分行动、内容结构与文体 / 学科视角；没有重建统一模板或复制既有格式规定。

## 可复用的阅读流程

1. **定义动作**：总结、解释或只改格式；format-only 仍不得擅改语义。
2. **确认结构**：论证、叙事、纪实、方法、对话或混合；一部书可以组合结构。
3. **选择文体视角**：历史政治、调查报告、理论哲学、演讲随笔、小说文学；视角叠加在结构上，不替代结构。
4. **核对文本与版本**：读取作品目录、序言、版本说明，记录译者、版次和材料完整度；页码只在能确定当前版本时使用。
5. **建立证据层级**：分别标注作品主张、同时代材料、后出研究、编辑说明、独立核实事实、整理者解释和未知。
6. **划分接力单元**：优先按实际论证 / 事件机制和篇幅决定，可跨章节或在长章内分段；每轮完成一个单元，并写明下一个单元。
7. **形成精读**：梳理文本提出的问题、论证 / 叙事过程、例证、反例、重要关系和限制；不以换句话说代替分析。
8. **复核与关联**：核对引用定位、来源可访问范围、表格与链接目标；更新该作品的唯一进度文件，不改写其他已完成项目。

## 表达视角补充：把精读写成我的阅读笔记

《寻乌调查》九单元完成后，用户指出主笔记偏“报告称、本文指出、本单元”的第三人称与会议纪要腔。现在统一调整：**以第一人称读者为主线，而不是以研究报告为主语**。各单元首先呈现读到某个场景、人物、事实或句子后产生的真实阅读问题，随后说明文本依据、理解如何形成、何处需要反向审视。事实归属仍用“原文记载/作者判断/后出研究”等准确语句，不因追求文学口吻而混淆证据；不强迫每句都用“我”，避免反复的抒情模板。正文少写工作流、验收、来源管理口吻；版本和进度留给作品导览及唯一进度文件。

小说精读尤其关注人物遭遇、语言细节、叙述者的讽刺、读者可能同时产生的同情与不适、人物选择的限制与伦理张力，以及文本的多义性；不要把小说硬写成政治研究提纲，更不能只摘录情节后贴“精神胜利法”标签。此规范对后续全部跨文体作品有效。

## 已有合订本的单篇深化规则

当用户提供或仓库中已经存在多篇作品的合订本，而其中某篇已有简要精读时，不应默认另建该篇的独立主笔记。先检查合订本中已有的情节理解、人物分析和跨篇主题，再把新的细读单元、场景回看和全篇反思融合到该篇原有位置；合订本的跨篇联读继续保留，不重复写第二套专题总论。版本、来源和阅读路线可以保留在单篇导览中；历史独立正文如需保留，改成指向合订本唯一正文的兼容入口。

## 路由清单

| 文体 | 主要关注 | 优先复用 |
| --- | --- | --- |
| 历史与政治分析 | 历史脉络、人物、制度、利益、政治力量、因果机制 | 新历史政治专项 + 观点分析 / 知识纪实 |
| 调查研究与报告 | 对象、方法、样本、材料分类、事实与推论 | 知识纪实；必要时方法笔记 |
| 理论与哲学 | 概念、前提、推理、关系和适用范围 | 观点分析；必要时知识纪实 |
| 演讲与思想随笔 | 核心命题、冲突、场合、听众和价值判断 | 观点分析 + 按实际结构叠加 |
| 小说与文学 | 情节、人物、视角、结构、主题和表达 | 叙事分析 + 小说深读；人文引导可选 |
